# 🎨 All-In-One Korean Poster Fonts Collection
> 상업적 이용 가능한 한글 포스터·타이틀·본문 무료 폰트 올인원 모음집 (SVG / PDF 임베딩 최적화)

[![GitHub Release](https://img.shields.io/github/v/release/kmsrepo/korean-poster-fonts?style=flat-square&color=blue)](https://github.com/kmsrepo/korean-poster-fonts/releases/latest)
[![License: Open Source](https://img.shields.io/badge/License-Commercial%20Free%20%2F%20OFL-green.svg?style=flat-square)](#-라이선스-안내)
[![Total Fonts](https://img.shields.io/badge/Fonts-39%20Families%20%2F%20144%20Files-orange.svg?style=flat-square)](#-카테고리별-수록-목록)

포스터, 현수막, 카드뉴스, 유튜브 썸네일, SVG 벡터 그래픽, 인쇄용 PDF 제작 시 즉시 활용할 수 있는 **상업적 무료 한글 폰트 39개 패밀리(총 144개 파일)** 를 디자인 목적별로 분류하여 패키징한 저장소입니다.

모든 폰트는 변환 손실이 없는 순수 **SFNT(OTF / TTF)** 원본 벡터 포맷으로 수록되어 있습니다.
